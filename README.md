# Bus Reservation System (Java)

A simple console-based Bus Reservation System developed in Java that simulates the ticket booking process at a bus booking office.

## Features

* View bus details
* Book tickets using passenger name, bus number, and travel date
* Check seat availability
* Confirm or reject bookings based on available seats

## Implementations

### 1. ArrayList Version

* Stores data in memory using Java Collections.
* No database required.
* Ideal for learning Core Java and OOP concepts.

### 2. JDBC Version

* Uses JDBC with MySQL for data storage.
* Booking information is stored permanently in a database.
* Demonstrates Java database connectivity.

## Technologies Used

* Java
* OOP Concepts
* ArrayList
* JDBC
* MySQL

## How to Run

1. Clone the repository.
2. Open the project in your Java IDE.
3. Run the desired version (ArrayList or JDBC).
4. Follow the console prompts to book tickets.
